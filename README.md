## 📝 About The Project
A classic Tic-Tac-Toe game built using Java Swing and AWT. This project was initially built by following a tutorial, but it has been heavily customized, redesigned, and expanded with several new interactive features to improve the user experience.

## ✨ Custom Features & Enhancements
While the core logic of the board was inspired by the base tutorial, the following features were completely custom-added to elevate the game:

* **🎨 Custom UI & Colors**: Replaced the default dark themes with a softer, modern color palette (using custom hex codes like `#dcedc8`) for a more aesthetically pleasing look.
* **👤 Starting Player Selection**: At the beginning of the game (and upon every restart), a dialog box prompts the user to choose whether they want to start as **'X'** or **'O'**. The game dynamically adjusts the first turn based on this choice.
* **🔄 Interactive Restart Button**: Added a dedicated restart button to the top panel. It resets the board, turn count, and colors instantly without needing to close and reopen the application. It also features a custom icon fetched directly from a URL.
* **🎵 Background Music System**: Integrated a `.wav` audio playback system that plays a relaxing piano track on a continuous loop. It includes a dynamic "Music: OPEN / OFF" toggle button on the top left corner to let players control the audio state anytime during gameplay.

## 🛠️ Built With
* **Java** (Core Game Logic)
* **Java Swing & AWT** (Graphical User Interface)
* **javax.sound.sampled** (Audio playback integration)
